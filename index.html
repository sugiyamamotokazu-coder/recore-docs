recore-daily-csv

個人の業務効率化のために作成した、非公開の自動化ツールです。一般公開や第三者への提供は行っていません。

このツールの役割

業務で使用しているシステムから出力したCSVファイルを、利用者本人のGoogle Driveに保存します。保存するのは、このツール自身が作成したファイルのみです。

Googleアカウントへのアクセス

権限は「drive.file」(このアプリが作成したファイルのみ)に限定しています。Google Drive内のその他のファイルの閲覧・変更・削除は行いません。

プライバシーポリシー

A private personal automation tool. It saves files it creates itself to the owner's own Google Drive using only the drive.file scope. It is not offered to the public or to third parties. See the Privacy Policy.
